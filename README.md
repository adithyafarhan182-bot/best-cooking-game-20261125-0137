Sizzle & Serve — Milo the cat chef's kitchen. Customer tickets slide onto the order board; you run the kitchen: grab ingredients from the pantry, chop lettuce and tomato, cook patties, pasta and soup on two burners (don't let them burn!), plate each dish to match its ticket, and serve it at the window before patience runs out. Fast serves pay tips, back-to-back serves build a combo, and three shift days raise the stakes from a first shift to a full dinner rush. Original art, sounds and names; plays offline in a desktop browser from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD / arrow keys to walk, E to interact, keys 1–6 to grab from the pantry, mouse works too, P to pause, M to mute.
